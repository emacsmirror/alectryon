This file shows how to process an HTML file with Alectryon. To compile it, use the following command:

      alectryon literate_HTML.html # HTML → HTML, produces ‘literate_HTML.annotated.html’

To use Alectryon with your own HTML file, just wrap your code in pre tags with the alectryon class. Use data-io to set processing annotations. Here are some examples:

      Require Import ZArith.
    
      Goal True /\ True.
        split. (* .unfold *)
        - exact I.
    
          Check nat. (* .unfold *)
        - exact I.
      Qed.

Use data-io="skip" to display a snippet with syntax highlighting but without invoking the prover:

      Check 1 + true. (* Never sent to Coq *)

Use data-strip="n" to strip indentation and leading/trailing newlines (0 for the indentation of the parent pre tag, n for additional indentation).
